# CARTE MULTI-DOWNLOADER

Self-hosted website to download videos and photos from **TikTok, Instagram, Facebook, X (Twitter)** and 1000+ other sites.

**Powered by yt-dlp** · Branded with the CARTEL Mult Engineering Ltd logo.

---

## Requirements

- Python 3.8+
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [ffmpeg](https://ffmpeg.org/) (needed for audio extraction and some merges)

### Install dependencies

**macOS**
```bash
brew install yt-dlp ffmpeg
```

**Ubuntu / Debian**
```bash
sudo apt update
sudo apt install ffmpeg
pip install -U yt-dlp
```

**Windows**
1. Download `yt-dlp.exe` from the official releases
2. Download ffmpeg and add both to your PATH

---

## How to run

1. Open a terminal in this folder
2. Run:
   ```bash
   python server.py
   ```
3. Open your browser at: **http://localhost:8080**

That’s it.

---

## Features

- Paste any public link from TikTok / Instagram / Facebook / X
- Choose Best quality / Audio only (MP3) / Photos
- Clean dark UI with the official CARTEL logo
- Works offline after the files are downloaded
- Completely self-hosted – no data leaves your machine
